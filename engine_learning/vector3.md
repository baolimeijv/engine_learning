# Vector3 笔记（极简版）

## 1. `operator+` 为什么返回对象，`operator+=` 为什么返回引用？
- `+` 不修改原对象，返回一个新对象（值返回），符合 `a + b` 产生新值的语义。  
- `+=` 修改当前对象，返回当前对象的引用（`*this`），支持链式操作（如 `a += b += c`），且避免不必要的拷贝。

## 2. 为什么成员函数后面要加 `const`？
- 表示该函数不会修改对象的成员变量（`x, y, z`）。  
- 这样 `const` 对象也能调用这些函数，同时让代码意图更清晰，编译器也能进行优化。

## 3. 点积和叉积的几何意义与公式？
- **点积**：`a·b = x?x? + y?y? + z?z? = |a||b|cosθ`，用于求夹角、投影、判断方向（正负表示前后）。  
- **叉积**：`a×b = ( y?z? - z?y?,  z?x? - x?z?,  x?y? - y?x? )`，得到一个垂直于 `a` 和 `b` 的向量，长度 = `|a||b|sinθ`，用于求法线、判断左右、计算旋转轴。

## 5. 为什么 `normalized()` 要判断长度是否接近 0？
- 浮点数中，极短向量（长度 < 1e-6）除以自身可能产生无穷大或 NaN，因此用阈值判断，直接返回原向量（或零向量）。

## 6. `operator/` 的语义是什么？
- 向量除以标量：`(x/a, y/a, z/a)`，每个分量除以标量。标量除以向量不重载。

## 7. 为什么需要友元 `operator<<`？
- 为了用 `cout << v` 打印向量，需要访问私有成员 `x,y,z`。声明为友元，返回 `ostream&` 支持链式输出。

## 8. 测试时如何验证叉积垂直？
- 计算 `a·(a×b)` 和 `b·(a×b)`，结果应接近 0（浮点误差允许）。
